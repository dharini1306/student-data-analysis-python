# Student Data Analysis using Python

## Project Description
This project performs basic data analysis on student data using Python.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Tasks Performed
1. Loaded CSV data using Pandas.
2. Calculated average marks.
3. Calculated average study hours.
4. Created a bar chart for student marks.
5. Created a scatter plot for study hours and marks.
6. Created a heatmap to analyze correlations.
7. Provided insights based on the analysis.

## Results
- Average Marks: 80.625
- Average Study Hours: 4.375 hours

## Conclusion
The analysis shows a strong positive relationship between study hours, attendance, and marks in the given dataset.
